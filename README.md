# 文件合并导出工具

一个基于 Tkinter 的桌面小工具，用于把多个文件按顺序合并导出到单个文本文件中。

## 功能

- 支持添加单个文件或递归添加整个目录
- 支持把文件或目录直接拖拽到列表区域导入
- 支持多选移除、上移、下移，便于控制导出顺序
- 自动去重，避免同一路径文件被重复加入
- 文本文件会尝试按 UTF-8、GB18030、GBK 等常见编码读取
- 二进制文件会输出十六进制预览，方便归档和排查
- 支持配置导出编码、换行风格、分隔符样式和分隔长度
- 状态栏显示文件数量和总大小

## 安装依赖

```bash
pip install -e .
```

## 运行方式

```bash
python main.py
```

也可以直接运行：

```bash
python File_merging_and_export_tool.py
```

## 快捷键

- Ctrl+O：添加文件
- Ctrl+S：导出合并文件
- Delete：移除选中文件

## 拖拽导入

- 直接把文件或目录拖到列表区域即可导入
- 拖入目录时会递归收集其中全部文件
- 如果拖入内容已经存在于列表中，会自动跳过重复项

## 导出说明

- 输出文件不能与待合并文件是同一路径
- 可以在主界面中设置导出编码、换行格式以及三类分隔符
- 分隔符支持输入多个字符，程序会按设定长度自动重复拼接
- 文本文件会保留原始内容，并在必要时补一个换行
- 无法识别为文本的文件会写入二进制说明和前 512 字节的十六进制预览
